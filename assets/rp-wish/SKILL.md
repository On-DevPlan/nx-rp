name: rp-wish
description: nx-rp wish —— 「愿望驱动循环」：调用 nx-rp 的 nx-loop（仅轮次模式、无关键词结束）强制 X 轮，每轮用 subagent 从用户的高层愿望出发自动调研（需扩展的目录、文件代码位置、新需求）并确定本轮代码范围与产出，逐步逼近愿望完成。触发词：愿望驱动、wish、自动迭代完成、让它自己做完、无关键词循环、subagent 自动生成需求、强制 X 轮。**不适用于**：成功判据可自动验证的任务（用承诺模式 + 手动 prompt 更直接）、一次性操作、需要人拍板的设计决策。
---
调用nx-loop 这个skill, 无关键词结束 强制x轮

完成用户的需求,  调用subagent自动生成需求  loop循环的设置不要过于具体 设置loop为大体的目录和注册

subagent的调研包括: 需要扩展的目录 文件代码位置 新的需求要求 等等  一定要确认对标的项目或者意向

确定每一轮的需求代码范围 以及agent完成的产出
